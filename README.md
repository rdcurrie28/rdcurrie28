## 🔭 Featured project

### [Headless Application Design: Customer Insights](https://github.com/rdcurrie28/Headless-Application-Design)

A headless sales intelligence platform. One typed REST API brings together **Snowflake** (entitlements, usage, ML propensity scores), **PostgreSQL** (accounts, contacts, next steps) and **S3** (customer documents) into a single *Customer 360* view, with a **React + PatternFly** front end as one of its clients.

- API-first design, so the same contract can serve a web app, a CRM widget, a chat bot or an AI agent
- Pages keep working when one data source fails, with each section loaded in parallel and its own timeout
- Type safety from end to end: OpenAPI → TypeScript
- Tested with pytest and Playwright, including desktop and mobile runs and accessibility scans
